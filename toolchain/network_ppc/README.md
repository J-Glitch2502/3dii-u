Wii U HTTP/TLS libraries from the local devkitPro portlibs SDK.

libcurl 8.7.1, Mbed TLS 2.28.8, zlib and Brotli decoder/common libraries: linking uses the SDK static libraries.
Headers and static libraries are for PowerPC/WUT. The Windows Builder ships these with its engine.
The embedded CA list is the Mozilla bundle distributed at https://curl.se/ca/cacert.pem (MPL 2.0).
